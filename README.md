# TweaksLab Free Panel

Panel Community gratuit (WPF / .NET 8) pour Windows.

## Lancer en local

```bat
go.bat
```

Ou :

```bat
Lancer-Panel.bat
```

## Prérequis

- Windows 10/11
- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
